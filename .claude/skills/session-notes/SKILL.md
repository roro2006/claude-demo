# Session notes

Write `.claude/sessions/<topic>.md` with exactly three sections:

## Worked
What succeeded, with evidence (passing test, commit hash, command output).

## Failed
What was tried and did not work, and why. This section matters most: it stops the next session repeating dead ends.

## Left to do
Concrete next steps, in order.
